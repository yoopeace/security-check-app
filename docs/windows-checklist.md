# 윈도우 PC 점검표

개인 윈도우 PC에서 `SecurityCheck.exe`를 직접 실행해 확인하는 항목.
자동 테스트가 확인하지 못하는 부분(실제 화면, 권한 창, 윈도우 보안 경고)을 사람이 확인함.

점검일: ____________ / 윈도우 버전: ____________ / 화면 배율: ______ %

## 1. 내려받기와 첫 실행

- [ ] GitHub Actions 최근 성공 실행의 Artifacts 에서 `SecurityCheck-windows` 를 내려받아 압축을 풂
- [ ] `SecurityCheck.exe` 를 두 번 누르면 "Windows의 PC 보호" 경고가 뜸 → "추가 정보" → "실행" 으로 넘어감
- [ ] 백신 프로그램이 파일을 지우거나 막는지 확인 (막으면 백신 이름과 메시지 기록)
- [ ] 창 제목이 "보안 점검 도구" 이고 탭 두 개("로그 분석", "파일 무결성")가 보임
- [ ] 인터넷(와이파이·랜선)을 끊은 상태에서도 똑같이 실행됨

## 2. 로그 분석 — 파일 열기

준비: 이벤트 뷰어 → Windows 로그 → 보안 → 오른쪽 "모든 이벤트를 다른 이름으로 저장…" → `.evtx` 로 저장 (관리자 권한 필요)

- [ ] 테스트용 계정으로 로그인을 일부러 3번 이상 틀린 뒤 보안 로그를 저장하고 [로그 파일 열기…] 로 분석
- [ ] 분석하는 동안 진행 표시와 "읽은 기록: N건" 이 바뀌고, 창을 움직여도 멈추지 않음
- [ ] [취소] 를 누르면 "분석을 취소했습니다" 로 돌아옴
- [ ] 결과의 "분석한 기록" 건수와 기간이 이벤트 뷰어의 보안 로그와 맞음
- [ ] 틀린 로그인이 기준(10분 40회, 24시간 8회) 미만이면 "로그인 반복 실패" 항목이 없음
- [ ] 시스템 로그(System)를 저장해 열면 "보안 로그가 아닙니다" 로 확인 필요가 뜸
- [ ] 아무 텍스트 파일 이름을 `.evtx` 로 바꿔 열면 앱이 꺼지지 않고 "읽을 수 없는 파일입니다" 가 뜸
- [ ] [보고서 저장…] 으로 저장한 `.txt` 를 메모장으로 열면 한글이 깨지지 않음

## 3. 로그 분석 — 이 PC 점검

- [ ] 일반(관리자 아님) 계정: 버튼 옆에 "관리자 권한이 필요합니다", 누르면 다시 실행할지 물음
- [ ] "예" → 윈도우 권한 확인 창(UAC) → 앱이 관리자 권한으로 다시 열림
- [ ] 관리자 권한으로 [이 PC 점검] → 지금 PC 의 보안 로그가 분석됨
- [ ] 분석이 끝난 뒤 `%TEMP%` 아래에 `SecurityCheck-` 로 시작하는 폴더가 남아 있지 않음

## 4. 파일 무결성

- [ ] 연습용 폴더를 만들고 [폴더 선택…] → "기준선이 없습니다" 안내가 뜸
- [ ] [기준선 만들기] → 초록 "이상 없음", "기준선을 만들었습니다: 파일 N개"
- [ ] 그대로 [검사하기] → 초록 "이상 없음"
- [ ] 파일 하나 내용 수정, 하나 삭제, 하나 추가 후 [검사하기] → 빨강 "위험 발견" 과 세 항목
- [ ] [기준선 만들기] 를 다시 누르면 확인 창이 뜨고, "취소"·창 닫기·Enter·Esc 모두 기준선을 바꾸지 않음
- [ ] 검사한 폴더 안에 앱이 만든 파일이 하나도 없음 (`snapshot.json` 등은 `%LOCALAPPDATA%\SecurityCheck\` 아래에 있음)
- [ ] 고급 설정에서 USB 에 비밀키 위치를 지정해 기준선 → 검사가 되고, USB 를 빼고 검사하면 "비밀키가 없어" 안내가 뜸
- [ ] 다른 프로그램이 열어 잠근 파일(예: 엑셀로 연 파일)이 있으면 "확인하지 못한 파일" 로 확인 필요가 뜸

## 5. 화면

- [ ] 화면 배율 100%, 125%, 150% 에서 글자가 잘리거나 겹치지 않음
- [ ] 창을 최소 크기로 줄여도 [보고서 저장…] 버튼이 보임
- [ ] 긴 폴더 경로·파일 이름이 표에서 읽을 수 있게 보임
